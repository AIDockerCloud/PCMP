# 项目核心定义 (PROJECT.md)

## 项目定位与宗旨
- **项目名称**：示例微服务 (Sample Microservice)
- **核心定位**：提供高内聚、低耦合的用户认证与鉴权核心能力。

## 核心目标 (Scope)
- 支持基于 JWT 的无状态认证与 Token 刷新；
- 提供安全的密码哈希存储（Argon2id）；
- 输出开箱即用的 RESTful HTTP API 与 OpenAPI 规范文档。

## 明确非目标 (Non-Goals)
- 不集成第三方 OAuth 社交登录（初期聚焦本地账号）；
- 不做分布式多租户隔离。

## 不得违反的硬约束 (Hard Boundaries)
1. 严禁以明文或仅使用 MD5/SHA-1 存储任何用户密码凭据；
2. 密钥与私钥严禁提交至 Git 仓库，必须通过环境变量注入；
3. 单元测试覆盖率核心鉴权模块不得低于 90%。
